## 🎬 카드 스프레드 애니메이션 - 4가지 스타일

### 1️⃣ **손 스타일 (Hand Style)** 🖐️
카드가 손에서 나와 테이블에 펼쳐지는 자연스러운 움직임
- 손 위치에서 출발
- 각 카드가 우아하게 회전하며 최종 위치로 이동
- 가장 현실적이고 아름다운 표현

**사용 시나리오:** 내담자가 직접 뽑은 카드를 배치할 때

### 2️⃣ **폭포식 (Cascade Style)** 💫
카드가 위에서 떨어지며 배치되는 동적 움직임
- 스타크한 시각 효과
- 카드가 회전하며 내려옴
- 빠른 속도감 표현

**사용 시나리오:** 신비로운 분위기 연출

### 3️⃣ **궤도식 (Orbital Style)** 🌀
카드가 원형으로 회전하며 배치되는 기하학적 움직임
- 중심에서 바깥쪽으로 확산
- 각 카드가 자신의 궤도를 따라 배치
- 신비로운 우주 에너지 표현

**사용 시나리오:** 전체 에너지 흐름을 보여줄 때

### 4️⃣ **물결식 (Wave Style)** 〰️
카드가 물결처럼 펼쳐지는 유동적 움직임
- 부드럽고 자연스러운 흐름
- 카드가 위아래로 진동하며 배치
- 깨달음과 흐름의 이미지

**사용 시나리오:** 변화와 성장의 여정 표현

## 📐 지원하는 스프레드 타입

### • 3카드 스프레드 (과거/현재/미래)
가장 인기 있는 기본 스프레드
- 상황의 흐름을 간단하게 파악
- 초보자부터 전문가까지 사용

### • 5카드 크로스 스프레드
중심 상황과 4방향 영향
- 위: 의식적 목표
- 아래: 무의식적 기반
- 왼쪽: 과거 영향
- 오른쪽: 미래 전망
- 중심: 핵심 상황

### • 켈틱 크로스 (10카드)
가장 복합적이고 깊이 있는 스프레드
- 현재 상황의 모든 측면을 분석
- 깊이 있는 상담에 최적

### • 9카드 스프레드
3x3 매트릭스 배치
- 균형잡힌 구도
- 시각적 대칭성

## 🚀 사용 방법

### 1. **카드 스프레드 애니메이션 실행** (독립형 HTML)

```bash
# 브라우저에서 직접 열기
card_spread_animation.html
```

**기능:**
- ▶ 애니메이션 시작: 선택한 스프레드의 카드 배치 애니메이션 재생
- ⟲ 초기화: 애니메이션 리셋
- 🔄 반복: 애니메이션 반복 재생
- 스타일 선택: 4가지 애니메이션 스타일 중 선택
- 스프레드 선택: 3/5/10/9 카드 스프레드 선택

### 2. **Luna Tarot App UI v3 통합** (React)

#### 설치
```bash
npm install
npm start
```

#### 구조
```
luna_tarot_app_ui_v3.jsx
├── Welcome Screen (모드 선택)
├── Setup Screen (질문 + 스프레드 선택)
├── Draw Screen (카드 선택 + 애니메이션)
└── Reading Screen (AI 해석)
```

#### 주요 기능
1. **내담자 모드**: 78장의 카드 중 직접 선택
2. **상담사 모드**: 자동 선택 또는 수동 배치
3. **역방향 처리**: 각 카드마다 역방향 토글
4. **AI 해석**: Claude API를 통한 상위 3% 수준의 해석
5. **카드 스프레드 애니메이션**: 선택한 스타일로 자동 표현

```javascript
// Canvas 기반 고성능 렌더링
```

### 타이밍 및 이징
```javascript
// 각 스타일별 맞춤형 이징 함수
```

- 최소 재렌더링으로 부드러운 움직임
