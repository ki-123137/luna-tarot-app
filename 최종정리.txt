단계 1️⃣ : GitHub 저장소 생성
─────────────────────────────
1. github.com 접속 → 로그인
2. 우측 상단 + 버튼 → New repository
3. Repository name: luna-tarot-app
4. Description: 타로 카드 스프레드 애니메이션 + AI 상담
5. Public 선택
6. Create repository 클릭

단계 2️⃣ : 로컬에서 업로드
─────────────────────────────
mkdir luna-tarot-app
cd luna-tarot-app
git init

# 파일 복사
cp card_spread_animation.html .
cp luna_tarot_app_ui_v3.jsx .

# README.md 생성 (최소 버전)
cat > README.md << 'READMEEOF'
# Luna Tarot App v3 🌙

카드 스프레드 애니메이션 + Claude AI 타로 상담 앱

## 🚀 빠른 시작

### 즉시 사용
card_spread_animation.html을 브라우저에서 열기

### React 앱
luna_tarot_app_ui_v3.jsx를 React 프로젝트에 import

## ✨ 특징
- 4가지 카드 스프레드 애니메이션
- 78장 전체 카드
- Claude AI 기반 해석

## 📁 파일
- card_spread_animation.html: 독립형 (추천!)
- luna_tarot_app_ui_v3.jsx: React 앱
READMEEOF

# .gitignore 생성
cat > .gitignore << 'GITEOF'
node_modules/
.env
.env.local
*.log
.DS_Store
GITEOF

# Git 업로드
git add .
git commit -m "✨ Luna Tarot App v3 - Card Spread Animation with AI"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/luna-tarot-app.git
git push -u origin main

Q: card_spread_animation.html을 GitHub에 올리면 즉시 사용 가능한가?
A: ✅ YES! 브라우저에서 파일을 열면 바로 애니메이션이 작동합니다.

Q: React 앱도 올려야 하나?
A: 선택사항입니다. card_spread_animation.html로도 충분하지만,
   개발자들을 위해 올리면 포트폴리오에 좋습니다.

Q: API 키를 GitHub에 올려도 되나?
A: ❌ 절대 금지! .gitignore에서 .env 파일을 제외하세요.
   Vercel에서는 환경변수로 관리합니다.

Q: 스크롤 막대가 안 보이는데?
A: 브라우저를 새로고침(Ctrl+R 또는 Cmd+R) 해보세요.
   또는 개발자 도구에서 캐시 비우기를 시도하세요.

Q: 파일이 너무 많은데?
A: GitHub에는 필수 4개 파일만 올리세요:
   1. card_spread_animation.html
   2. luna_tarot_app_ui_v3.jsx
   3. README.md
   4. .gitignore
